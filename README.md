# Tools BD

Free, browser-only calculators and utilities for Bangladesh & NRBs built with Next.js 16 (App Router), TypeScript, Tailwind CSS v4, and Vitest.

## Commands (Windows PowerShell)

```powershell
npm.cmd run dev        # Start local dev server (http://localhost:3000)
npm.cmd run typecheck  # TypeScript check
npm.cmd run lint       # ESLint
npm.cmd test           # Vitest unit tests
npm.cmd run build      # Production static build
```

See [AGENTS.md](./AGENTS.md) for engineering rules, [project-scope.md](./project-scope.md) for product strategy, and [implementation-plan.md](./implementation-plan.md) for the sprint roadmap.
